## 1. INVARIANTS (do not touch without explicit `[INVARIANT-CHANGE]` request)

### 1.1 Pack Schema
- A Pack is `{ id, video_url, title, source_lang, output_lang, mode, summary, transcript, flashcards[], quiz[], lens_id, created_at }`
- Pack IDs are deterministic: `pack_<hash(video_url + lens_id + output_lang)>`
- Flashcards use FSRS scheduling (NOT SM-2 — migration planned Week 1 post-launch)
- All AI-generated outputs include `provenance: { model, lens_id, watermark: "vozclara.app" }`

### 1.2 Lens API Contract (LOCKED — no breaking changes)

```typescript
interface Lens {
  id: string;                    // e.g. "format.anki", "interpretive.marxist"
  category: 'format' | 'interpretive';
  name: string;
  description: string;            // shown in UI hover preview
  system_prompt: string;          // cached in Anthropic (1h TTL)
  output_format: 'markdown' | 'anki_apkg' | 'json' | 'latex' | 'tiktok_script';
  tier_required: 'free' | 'pro' | 'pro_plus';
  available_for_modes: ('learn' | 'brief' | 'study' | 'creator')[];
  context_match?: (video_metadata) => boolean;  // optional filter
}
```

### 1.3 Tier Routing (LOCKED)
- `free`: 3 videos/week, Llama 3.3, summary + transcript only
- `pro`: unlimited, Llama 3.3, all reading modes, 8 format-lenses
- `pro_plus`: above + Sonnet 4.5, 10 interpretive lenses, Season Pack 2/month
- Quotas enforced in worker, NEVER in client (security)

### 1.4 Privacy / Compliance
- AI disclosure banner shown on first pack-generate (EU AI Act Art 50 prep)
- Watermark in every export (.apkg + PDF + Markdown): "Generated by VozClara — vozclara.app"
- NO cookie banner (Cloudflare Web Analytics cookieless + no browser Sentry)
- `/privacy` lists all subprocessors: Anthropic, Cloudflare, Supadata, Polar/Stripe, Resend
- DSGVO Art 17: account deletion sweeps sessions + votes + reviews (already in `worker/src/auth.ts`)

### 1.5 Tech Stack Decisions (LOCKED)

- LLM Pro Plus: `claude-sonnet-4-5` via Cloudflare AI Gateway

## 3. Coding Conventions

### 3.1 TypeScript

- Strict mode always
- No `any` — use `unknown` + narrowing
- Zod for runtime validation at API boundaries
- Explicit return types on exported functions
- Functions <50 lines preferred, <100 lines max

### 3.2 React

- Functional components only
- Hooks-based state (no Redux)
- Tailwind for styling (NO inline styles, NO CSS modules)
- Editorial brand colors via Tailwind config: `navy`, `gold`, `gold-deep`, `creme`, `graphit`
- Typography: per-locale via `:lang()` CSS variables (Phase 2)

### 3.3 Worker

- `env.AI.run()` for Workers AI calls (Llama 3.3)
- `callAnthropic()` from `worker/src/anthropic.ts` for Sonnet 4.5
- ALWAYS set `max_tokens` on Anthropic calls (never default)
- ALWAYS `cache_control: { type: 'ephemeral', ttl: '1h' }` on Lens system prompts
- Tier check FIRST: `if (tier !== 'pro_plus') return 403`
- Use `ctx.waitUntil()` for usage logging (not in main response)

### 3.4 Error Handling

- User-facing errors: clear, actionable, i18n'd
- Worker errors: log to Sentry server-side
- Never leak stack traces to clients
- Retries: AI Gateway handles upstream retries — don't double-retry
- Rate-limit errors return 429 with `Retry-After` header

### 3.5 Commit Messages

```
<scope>: <imperative summary>

<optional body explaining why, not what>

Co-Authored-By: Claude Opus 4.7 (1M context) <noreply@anthropic.com>
```

Scopes: `worker`, `frontend`, `lens`, `mcp`, `compliance`, `docs`, `meta`.
